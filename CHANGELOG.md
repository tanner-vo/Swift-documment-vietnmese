# Changelog

All notable changes to this project will be documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases
will follow [Semantic Versioning](https://semver.org/) when the project reaches
a stable release process.

## [Unreleased]

### Added

- Open-source licenses, governance, contribution and security documentation.
- GitHub issue/PR templates, CI and dependency update configuration.
- Maintainer authentication for manual translation mutations.
- Public roadmap and Codex/OpenAI maintainer automation plan.

### Security

- Manual translation writes are disabled by default on public deployments.
- Translation mutations require a long maintainer bearer token and same-origin
  validation.

## [0.1.0] - 2026-03-24

### Added

- Initial bilingual Swift documentation reader.
- DocC JSON/HTML parsing, translation cache and manual overrides.
